## 📋 ขั้นตอนการทำงาน

### Step 1 — ทำความเข้าใจ Data Dictionary

เปิดไฟล์ `datadict.csv` เพื่อดูนิยามของแต่ละ column ที่ต้องการในผลลัพธ์

- ทำความเข้าใจแต่ละ field ว่าหมายถึงอะไร
- สังเกต format ของข้อมูล เช่น ประเภท, รูปแบบ, และค่าที่อนุญาต

### Step 2 — ศึกษา Output Format

เปิดไฟล์ `_Requirement_20261020.csv` เพื่อดูตัวอย่าง format ผลลัพธ์ที่ถูกต้อง

- สังเกต header ของแต่ละ column
- สังเกต format ของข้อมูลในแต่ละ column (เช่น วันที่, ตัวเลข, ข้อความ)
- ใช้ไฟล์นี้เป็น **template** สำหรับ output

### Step 3 — อ่านข้อมูล Input

เปิดไฟล์ Excel ทั้ง 2 ไฟล์:

1. `ก๊าสเรือนกระจก (แจกท่อ)  จังหวัดกาญจนบุรี ป.xlsx`
2. `ก๊าสเรือนกระจก (แจกท่อ) จังหวัดสุพรรณบุรี ป.xlsx`

สำรวจข้อมูลในแต่ละไฟล์:
- มีกี่ sheet
- header ของแต่ละ column คืออะไร
- มีข้อมูลกี่แถว

### Step 4 — Cleansing ข้อมูล

ตรวจสอบและแก้ไขปัญหาข้อมูลที่พบบ่อย ได้แก่:

| ปัญหา | สิ่งที่ต้องทำ |
|---|---|
| ค่าว่าง (Null / Missing) | ระบุว่า column ไหนมีค่าว่าง ***ไม่ให้ drop row ข้อมูลจะหาย*** |
| Format ไม่ตรง | เช่น วันที่รูปแบบต่างกัน, มีช่องว่างหน้า/หลัง, ตัวพิมพ์ใหญ่/เล็ก |
| ค่านอกขอบเขต (Outlier) | เช่น พิกัด Latitude/Longitude ที่ผิดปกติ |
| Encoding ภาษาไทย | ตรวจสอบว่าภาษาไทยแสดงผลถูกต้อง |
| `cust_code` ซ้ำผิดปกติ | ตรวจสอบตาม rule ด้านล่าง |

> ⚠️ **Rule: cust_code**
> - ลูกค้า **1 คน** ต้องมี `cust_code` **เพียงรหัสเดียว** เท่านั้น
> - ลูกค้า 1 คน **อาจมีหลายแปลงที่ดิน** ได้ → แต่ละแปลงต้องระบุ **เลขที่แปลง (lndval)** ที่**ไม่ซ้ำกัน**
> - หากพบว่า `cust_code` เดียวกันมีเลขที่แปลงซ้ำกัน → ให้ flag ไว้และถามพี่ก่อน **ห้าม** ลบทิ้งเอง

**หากไม่เข้าใจให้ถามพี่น้ำก่อน**

### Step 5 — Transform & Map ข้อมูล

แปลง column จากรูปแบบ input ให้ตรงกับ output ตาม `datadict.csv`:

- **Rename** column ให้ตรงกับ header ใน `_Requirement_20261020.csv`
- **Map ค่า** เช่น `cust_code` ต้องใส่ prefix ตามจังหวัด (`S` = สุพรรณบุรี, `K` = กาญจนบุรี)
- **`cust_code` ต้องใส่ปีบัญชีด้วย** ตามจังหวัด (`S` = สุพรรณบุรี, `K` = กาญจนบุรี)
- **Combine** ข้อมูลจากทั้ง 2 จังหวัดเข้าด้วยกัน

### Step 6 — Export ผลลัพธ์

บันทึกผลลัพธ์เป็นไฟล์ CSV:

- ชื่อไฟล์: `output_cleansed_YYYYMMDD.csv`
- Encoding: **UTF-8 with BOM** (เพื่อรองรับภาษาไทย)
- ตรวจสอบว่า header และ format ตรงกับ `_Requirement_20261020.csv`
